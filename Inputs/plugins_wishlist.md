\# Plugin Wishlist (Top 10)



\## Ranking (1 = highest priority)

1\) Export Presets + Batch Export

&nbsp;  - One-click presets: (web, print, pdf)

&nbsp;  - Batch export selected files or entire folder

&nbsp;  - Output naming templates



2\) Templates \& Snippets

&nbsp;  - Template gallery (project kickoff, flowchart, meeting notes)

&nbsp;  - Save current canvas as a template

&nbsp;  - Quick-insert snippets library



3\) Local Search + Tags + Index

&nbsp;  - Background index of file names + tags + embedded text

&nbsp;  - Full-text search in drawings (elements text)

&nbsp;  - Tagging UI (per file + per folder)



4\) Library Pack Browser

&nbsp;  - Browse/manage Excalidraw libraries (.excalidrawlib)

&nbsp;  - Import/export libraries

&nbsp;  - Per-profile libraries folder



5\) Presentation Mode (Frames -> Slides)

&nbsp;  - Slide view from frames

&nbsp;  - Next/prev + presenter notes

&nbsp;  - Export to PDF slides



6\) Markdown Embed/Export

&nbsp;  - Export a drawing and generate markdown snippet referencing it

&nbsp;  - Support frontmatter metadata for my vault system



7\) Import Pack

&nbsp;  - Import SVG/PNG/JPEG as background or elements

&nbsp;  - Basic SVG-to-elements conversion where possible



8\) Plugin Manager

&nbsp;  - Install from local zip/folder

&nbsp;  - Enable/disable per profile

&nbsp;  - Manifest validation + permissions UI

&nbsp;  - Update/replace plugin version



9\) Git Helper (optional)

&nbsp;  - If workspace is a git repo:

&nbsp;    - show status, commit exports

&nbsp;  - Must be optional and permission-gated



10\) “Review Mode” (Collaboration-lite)

&nbsp;  - Local-only: multiple cursors or comment pins

&nbsp;  - No cloud; LAN optional only if safe and easy



\## Plugin constraints

\- All plugins must be open-source compatible and runnable offline.

\- Plugins must not get unrestricted filesystem access unless explicitly granted.

\- Prefer first-party plugins living in /plugins/ in the repo for simplicity.



\## Success definition

\- A non-technical user can install/enable/disable a plugin without breaking the app.

\- Plugins can add toolbar buttons, export actions, panels, and menu items.
