# Library Pack Browser (first-party)

Manage Excalidraw `.excalidrawlib` libraries per profile.

- Import a `.excalidrawlib` pack, browse its item count, and insert its items
  onto the canvas.
- Save the current selection into a library for reuse across drawings.
- Libraries live under the profile's `libraries/` folder.

Contributes the *Open Libraries panel* command. `filesystem: workspace-only`,
`network: none`.
