# Templates & Snippets (first-party)

A gallery of reusable starting points.

- **Templates** — insert a saved scene as a brand-new drawing, or save the
  current canvas as a template. Stored per profile under `templates/`.
- Seeded by the AI Import Lane (`template_pack` payloads).

Contributes a **Templates** toolbar button and the commands *New drawing from
template…* and *Save current canvas as template…*. Declarative and
permission-scoped (`filesystem: workspace-only`).
