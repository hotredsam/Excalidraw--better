# Presentation Mode (first-party)

Turn the **frames** in a drawing into an ordered slide deck.

- Frames become slides in reading order (left-to-right, top-to-bottom).
- Each slide can hold presenter notes (stored alongside the workspace in
  `.excalibur/slides/`).
- Navigate with the on-screen controls or arrow keys; `Esc` exits.

Contributes a **▶ Present** toolbar button and a *Start presentation* command
(default `F5`). No filesystem writes beyond presenter notes; `network: none`.
